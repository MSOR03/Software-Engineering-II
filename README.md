# Tarea API REST y GraphQL

Este repositorio contiene el desarrollo de la actividad sobre consumo de APIs usando dos enfoques diferentes: REST y GraphQL. En cada carpeta se incluyen las respuestas a las preguntas de la tarea, una breve explicacion de la API utilizada y evidencias visuales de las peticiones realizadas.

## Contenido del repositorio

- [REST](REST/README.md): documentacion de las consultas realizadas a la API de Rick and Morty, incluyendo personajes, episodios y ubicaciones.
- [GraphQL](GraphQL/README.md): documentacion de consultas realizadas sobre una API GraphQL de paises, continentes e idiomas.

## Objetivo

El objetivo de esta tarea es comparar la forma en que se consumen datos en una API REST frente a una API GraphQL, identificando diferencias en estructura, cantidad de peticiones necesarias y flexibilidad al momento de consultar informacion.

## Evidencias

Cada carpeta incluye capturas de pantalla de las peticiones ejecutadas, con su respectiva descripcion, para dejar evidencia del trabajo realizado.
