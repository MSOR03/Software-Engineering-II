## 📌 Descripción

Este repositorio contiene las actividades, talleres y proyectos desarrollados durante la asignatura **Ingeniería de Software II**.  
Cada actividad se encuentra organizada en ramas independientes para facilitar su navegación y revisión.

---

## 📂 Contenidos

A continuación se listan las principales actividades del curso:

### 🔹 1. Principios SOLID
- 📍 Rama: `solid-principles`
- 📖 Descripción: Implementación y explicación de los principios SOLID aplicados en ejemplos prácticos.

---

### 🔹 2. API REST y GraphQL
- 📍 Rama: `API-REST-GraphQL`
- 📖 Descripción: Consumo de APIs públicas utilizando REST y GraphQL, incluyendo pruebas en Postman y documentación de resultados.

---

## 🛠️ Tecnologías utilizadas

- Postman  
- APIs REST públicas  
- GraphQL  
- JavaScript (tests en Postman)
